# Documentation feedback and contributions

This is a public documentation and educational publication, **not** an open-source engine contribution portal.

Useful feedback includes:

- unclear explanations or terminology;
- errors in quoted public metrics and their evidence boundaries;
- references to established related work that should be acknowledged;
- responsible critiques of evaluation methodology or generalization;
- usability questions relevant to future documentation.

Do **not** submit private source, unreleased internal data, access credentials, confidential test materials, unreviewed security findings or purported source-engine patches here.

Project maintainers may curate or decline suggested changes to protect intellectual property, privacy and research integrity. No formal contribution license is provided; contact maintainers before submitting substantive copyrighted material.
