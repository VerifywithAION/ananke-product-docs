# Glossary

| Term | Meaning in the ANANKE documentation |
| --- | --- |
| **Inference** | A new model execution producing a result, with actual compute and often tokens consumed |
| **Necessity Engine** | Independent decision layer determining whether an obligation needs new intelligence |
| **Zero-inference resolution** | An admissible result obtained without calling a fresh model |
| **Validated reuse** | Use of prior computation after required provenance and present-applicability checks |
| **Computational Capital (CC)** | Validated reusable computation with bounded future applicability and evidence |
| **Canonical authority** | The trusted, governed source of identity, policy, validation or source state |
| **Source revision / drift** | A change that may make a previous result inapplicable |
| **Selective invalidation** | Recomputing work affected by a change while preserving still-valid independent work |
| **Residual obligation** | The portion of work not satisfied by deterministic proof or valid Capital |
| **Minimum Admissible Intelligence (M06)** | Selecting a supported, sufficient and authorized intelligence tier for residual work |
| **Provider admission (M07)** | Whether the configured provider may execute under policy, budget and safety controls |
| **Receipt / proof** | Inspectable decision and evidence link, with scope and measured or labeled usage |
| **Fresh Inference Ratio** | A workload-specific quotient describing the amount of work requiring new inference, under a defined numerator/denominator |
| **Frontier-call reduction** | Fewer invocations of a larger frontier model; distinct from all-model call reduction |
| **False reuse** | Applying an old result when it was not eligible or valid for the new obligation |
| **False inference suppression** | Avoiding a necessary model execution without an admissible substitute |
| **Offline PASS** | Focused code/fixture qualification, not necessarily product-wide live acceptance |
| **Native E2E** | Real integrated local request journey with genuine backing services and evidence |
| **Counterfactual savings** | Estimated avoided work relative to a separately defined baseline |
