# Security and responsible disclosure

This is a **documentation-only repository**. It is not a running API, public binary, authentication system, SDK distribution or disclosure of the private ANANKE source.

## What must never be committed here

- API keys, personal credentials, authentication cookies or recovery material.
- Private repository source, internal process scripts or unpublished implementation contracts.
- Raw customer data, private prompts, test cases with restricted rights or provider logs.
- Internal machine paths, database connection strings, live infrastructure addresses or unredacted forensic artifacts.
- Unreviewed patent claims, unpublished legal strategy, confidential source hashes or proprietary proofs.

## Reporting a suspected issue

Do not open a public issue containing credentials, exploitable internal details or personal data. Use a private communication channel agreed with the project maintainers. **No official security mailbox, bug-bounty program, or guaranteed response time is represented by this repository.**

The absence of published code does not mean the underlying private product is security certified. See [Governance & safety](docs/governance-and-safety.md).
