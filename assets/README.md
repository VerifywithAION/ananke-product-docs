## Design language

- **Obsidian** — #071713, #0c1f19; conveys engineering focus.
- **Emerald** — #73eeb3, #8cf1b9; emphasizes the product's necessity and validation thesis.
- **Muted gold** — #e8cb8f; highlights evidence, judgment and exceptional decisions.
- **Supporting text** — off-white and sage; retain readable contrast.
- **Typography** — standard system sans-serif fonts; no remote fonts or font files.
- **Motion** — intentionally absent; this repository is a **GitHub-only reading experience**, not a separate website.

**Public copy standards:** never mix experimental savings with current customer ROI; identify specific experiments, disclose failed gates, and separate product intent from accepted engineering. See [Responsible claims](../CLAIMS.md).

## Optional GitHub repository social preview

The **source** is [ananke-social-preview.svg](ananke-social-preview.svg), designed at 1280×640. GitHub's repository-level Social Preview is configured in repository settings rather than via a Markdown file. If an image is desired when sharing the GitHub repository:

1. Export the SVG as a **1280×640 PNG** using a trusted local image editor.
2. Open the repository **Settings → General → Social preview** (requires the relevant repository permission).
3. Upload the exported PNG there. This step is **separate from committing an SVG to the repository**.

No social-preview setting is claimed to have been applied automatically by this documentation change.
