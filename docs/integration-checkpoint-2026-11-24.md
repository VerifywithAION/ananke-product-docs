## Technical and evidence boundaries

**Qualification is not Capital admission.** The historical laboratory checker remains intentionally non-promotable. Multi-dataset correctness checks are necessary but insufficient: product eligibility also requires independent authorization, source binding, actual model execution and durable trustworthy receipts.

**Deterministic baseline insufficiency is not proof of model necessity.** A bounded rule translator did not cover a joined, grouped SQL task; this does not establish that an alternative deterministic system could not solve it.

**Reusing a SQL query is not the same as caching its answer.** Data, schema, permissions and freshness can change, requiring new query execution or invalidation.

**Historical experiments remain separate.** The Token Reduction Lab Ollama studies and ANANKE × JEV external-provider studies have their own task populations and measured outcomes. They cannot be merged or advertised as this candidate's current economic results.
